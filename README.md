# Batı Sonrası Dünya

Astro ve GitHub Pages ile hazırlanmış kitap tanıtım ve yayın sitesi.

## Yükleme
Bu ZIP içindeki dosyaların tamamını GitHub deposunun köküne yükleyin. Ardından Settings → Pages → Source bölümünde GitHub Actions seçili olmalıdır.

## Geçici adres
https://mehmetalidemirk-ux.github.io/batisonrasi/

Alan adı geçişi site test edildikten sonra yapılacaktır.


## Not
Bu sürümde Erdapfel küresi motifi ve favicon entegre edildi. Ancak telifsiz harici görseller bu ortamda doğrulanamadığı ve kullanıcı talebi gereği yapay görsel kullanılmadığı için makale/yazar fotoğrafları otomatik eklenmedi. Bunun yerine dosya yolları hazırlandı:

- `public/images/authors/mustafa-kutlay.jpg`
- `public/images/authors/ziya-onis.jpg`
- `public/images/posts/brics-rio.jpg`
- `public/images/posts/esitsizlik-demokrasi.jpg`

Bu dört görsel eklendiğinde komponentler hızlıca güncellenebilir.
